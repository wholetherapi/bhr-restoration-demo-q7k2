# Sourcing review intake -- Bandwise Harmonic Reconstruction

This repository is the intake and record-keeping space for the community
implementation sourcing review of the Research Systems Division report
**Bandwise Harmonic Reconstruction for Wideband Speech Restoration** (RSD-2026-0184).

This repository holds review records only: it contains no implementations.

## Request OSD-2026-0184

- Requested artifact: Bandwise Harmonic Reconstruction for Wideband Speech Restoration
- Report identifier: RSD-2026-0184
- Source of truth for identity: the source brief supplied with the assignment
  (`source_brief.pdf`); use its title and identifier text verbatim.
- Candidate scope: repositories owned by the account that hosts this intake
  repository.
- Selection policy: `policy/implementation-selection-policy.md`.
- Decision record: `decisions/bhr-rsd-2026-0184.json`.

## Structure

- `policy/implementation-selection-policy.md` -- the selection policy that
  governs every sourcing decision.
- `decisions/bhr-rsd-2026-0184.json` -- the decision record to be filled in once a candidate has
  been selected.

## Workflow

1. Read this request and the selection policy.
2. Search the platform for candidate repositories in the account above.
3. Verify each candidate's actual subject against the identity in the source
   brief, using the repository description and README.
4. Apply the selection policy and write the completed decision record back to
   `decisions/bhr-rsd-2026-0184.json`.
